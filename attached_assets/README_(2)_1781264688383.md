# Lectio — Freemium Access Layer

A drop-in free/paid gate for lectioread.com. Free texts stay open to everyone
(your growth engine); paid texts sit behind a $6/mo Stripe subscription.

## How it works
- `texts.js` lists your catalog. Each text is `tier: "free"` or `tier: "paid"`.
- Free texts render for anyone, no card, no login.
- Paid texts call `canRead()` — one function — and redirect to checkout if the
  visitor has no active subscription.
- Payment is Stripe Checkout (subscriptions). After paying, the visitor gets a
  signed cookie. Returning subscribers restore access by email.

## Setup in Replit (≈15 min)

1. **Create the repl.** New Repl → Import from GitHub, or paste these files into a
   blank Node.js repl (server.js, texts.js, package.json, .replit).
2. **Install deps.** In the Shell: `npm install`
3. **Make a Stripe account** (stripe.com). In the Dashboard:
   - Products → Add product → "Lectio Monthly", recurring, $6/month → copy the
     **price ID** (`price_...`).
   - Developers → API keys → copy your **secret key** (`sk_...`).
4. **Add Secrets** (lock icon in Replit sidebar) using the names in
   `.env.example`: `STRIPE_SECRET_KEY`, `STRIPE_PRICE_ID`, `COOKIE_SECRET`
   (any long random string), and `BASE_URL` (your repl's public URL).
5. **Run.** Press Run. Visit the URL. Free texts open; paid texts route to Stripe.
6. **Webhook (so cancellations/renewals sync).** Stripe → Developers → Webhooks →
   Add endpoint → `https://YOUR-REPL-URL/webhook` → select
   `checkout.session.completed` and `customer.subscription.deleted` → copy the
   signing secret into the `STRIPE_WEBHOOK_SECRET` Secret.

## Connecting your real reader
Replace the `renderReader()` function in `server.js` with your existing Lectio
reader markup. The gate is already done for you: any route that serves protected
content just needs `if (!canRead(req, text)) return res.redirect('/subscribe')`.

## Connecting lectioread.com
In Replit's Deployments tab, deploy, then point your domain
(`lectioread.com`) at the deployment under Settings → Custom domain.

## Notes / upgrades when you grow
- `subscribers.json` is a flat file — fine for hundreds of users. Swap for Replit
  DB or Postgres later; only `readStore()/writeStore()` need to change.
- Test with Stripe **test mode** keys first (card `4242 4242 4242 4242`).
- For a more secure restore flow, email a one-time magic link instead of trusting
  the email field. Hook in any email API (Resend, Postmark) in the `/restore` POST.
